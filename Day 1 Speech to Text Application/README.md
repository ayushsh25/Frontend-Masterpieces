# 🎤 Speech to Text Application

A responsive and interactive **Speech to Text Application** built using **HTML**, **CSS**, and **JavaScript**. This project uses the **Web Speech API** to convert spoken words into text in real time through the browser. It demonstrates speech recognition, DOM manipulation, event handling, and responsive web design without requiring any external libraries.

## ✨ Features

- 🎙️ Real-time speech-to-text conversion
- 📝 Live transcription using the Web Speech API
- 🎤 One-click microphone access
- 📋 Copy transcribed text easily
- 🗑️ Clear text with a single click
- 📱 Responsive design for desktop and mobile
- ⚡ Lightweight and fast performance
- 🌐 Works in supported modern browsers

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Web Speech API

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Speech-To-Text-Application.git
   ```
2. Open the project folder.
3. Run `index.html` in your preferred web browser.
4. Allow microphone access when prompted.
5. Click the **Start Listening** button and begin speaking.

## 💡 How It Works

- The browser requests permission to use your microphone.
- The Web Speech API captures and processes your voice.
- Recognized speech is displayed instantly in the text area.
- You can copy or clear the generated text anytime.
