# 🎹 Piano Application

An interactive and responsive Piano Application built using **HTML**, **CSS**, and **JavaScript**. Users can play piano notes by clicking the piano keys or pressing corresponding keyboard keys. This project demonstrates DOM manipulation, keyboard event handling, and audio playback using JavaScript.

---

## ✨ Features

- 🎼 Play piano notes using mouse clicks
- ⌨️ Keyboard support for playing notes
- 🔊 Realistic piano sound effects
- 📱 Responsive design for desktop and mobile
- 🎨 Clean and modern user interface
- ⚡ Fast and lightweight application

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
