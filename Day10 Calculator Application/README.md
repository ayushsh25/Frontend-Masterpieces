# 🧮 Calculator Application

A simple, responsive, and user-friendly Calculator Application built using **HTML5**, **CSS3**, and **JavaScript**. This web application performs basic arithmetic operations such as addition, subtraction, multiplication, and division with real-time results. It is designed to demonstrate JavaScript logic, DOM manipulation, and responsive web design.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear (AC) functionality
- ⌫ Delete (DEL) last input
- ⚡ Instant calculation
- 📱 Responsive design
- 🎨 Clean and modern UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
