# 📖 Read More / Less

A simple and interactive **Read More / Less** web application built using **HTML5, CSS3, and JavaScript**. The project allows users to expand or collapse lengthy text content with a single click, helping maintain a clean and organized webpage layout.

The application demonstrates how JavaScript can be used to dynamically control the visibility of HTML content and create an interactive user experience.

---

## 🚀 Features

- 📖 Expand hidden content with **Read More**
- 📕 Collapse content with **Read Less**
- ⚡ Instant content visibility changes
- 🎨 Clean and simple user interface
- 📱 Responsive design
- 🖱️ Interactive button functionality
- 🌐 Runs directly in the web browser

---

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling and responsive design
- **JavaScript** – Dynamic content functionality and DOM manipulation

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Read-More-Less.git
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

4. Click the **Read More** button to display additional content.

5. Click **Read Less** to collapse the content again.
