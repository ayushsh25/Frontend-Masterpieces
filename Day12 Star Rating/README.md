# ⭐ Star Rating Application

A simple and interactive **Star Rating Application** built using **HTML5, CSS3, and JavaScript**. The project allows users to select a rating by clicking on stars and provides an interactive visual representation of their selection.

This project demonstrates the implementation of interactive UI components using JavaScript, DOM manipulation, event handling, and dynamic CSS styling.

## 🚀 Features

* ⭐ Interactive star-based rating system
* 🖱️ Click stars to select a rating
* 🔄 Dynamically updates the selected rating
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* ⚡ Fast and lightweight
* 🌐 Runs directly in the browser

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and star effects
* **JavaScript (ES6)** – Rating functionality and user interaction

## ▶️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/Star-Rating.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Click on the stars to select your desired rating.
