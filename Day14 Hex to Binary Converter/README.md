# 🔢 Hexadecimal to Binary Converter

A simple and interactive **Hexadecimal to Binary Converter** built using **HTML5, CSS3, and JavaScript**. The application allows users to enter a hexadecimal value and quickly convert it into its corresponding binary representation.

This project demonstrates JavaScript fundamentals, number-system conversion, DOM manipulation, input validation, and event handling.

## 🚀 Features

* 🔢 Convert hexadecimal values to binary
* ⚡ Fast and accurate conversion
* ✅ Input validation
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 🌐 Runs directly in the browser
* 💻 Lightweight and easy to use

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Conversion logic and DOM manipulation

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Hex-to-Binary-Converter.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a hexadecimal value.
5. Click the **Convert** button.
6. The corresponding binary value will be displayed.

## 💡 Example

```text
Input:  A5

Output: 10100101
```
