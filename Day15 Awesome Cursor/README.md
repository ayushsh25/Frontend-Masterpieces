# 🖱️ Awesome Cursor

**Awesome Cursor** is an interactive frontend web project built using **HTML5, CSS3, and JavaScript**. It enhances the user experience by replacing the default cursor with a customized animated cursor and interactive visual effects.

The project demonstrates how JavaScript can be used to track mouse movements and create dynamic UI interactions.

## 🚀 Features

* 🖱️ Custom animated cursor
* ✨ Smooth cursor movement
* 🎨 Attractive visual effects
* ⚡ Real-time mouse tracking
* 💻 Interactive user experience
* 📱 Responsive frontend design
* 🌐 Runs directly in the browser
* 🪶 Lightweight and easy to use

## 🛠️ Technologies Used

* **HTML5** – Page structure and content
* **CSS3** – Styling, animations, and cursor effects
* **JavaScript** – Mouse tracking and interactive behavior

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Awesome-Cursor.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Move your mouse around the webpage to experience the custom cursor effects.
