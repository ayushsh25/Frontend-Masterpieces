# 🖼️ Image Comparison Slider

**Image Comparison Slider** is an interactive frontend web application built using **HTML5, CSS3, and JavaScript**. It allows users to compare two images side-by-side using a draggable slider, making it easy to visualize differences between a **before** and **after** image.

This project demonstrates DOM manipulation, mouse and touch events, CSS positioning, and interactive UI development.

## 🚀 Features

* 🖼️ Compare two images interactively
* ↔️ Smooth draggable comparison slider
* 🔄 Before-and-after image comparison
* 🖱️ Mouse interaction support
* 📱 Responsive design
* ✨ Smooth and engaging UI
* ⚡ Lightweight and fast
* 🌐 Runs directly in the browser

## 🛠️ Technologies Used

* **HTML5** – Structure and image elements
* **CSS3** – Layout, styling, positioning, and transitions
* **JavaScript (ES6)** – Slider functionality and user interaction

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Image-Comparison-Slider.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Drag the slider from left to right to compare the two images.

## 💡 How It Works

The application places two images on top of each other. A draggable slider controls the visible portion of the top image.

As the user moves the slider, JavaScript dynamically adjusts the image container width, allowing the user to view the difference between the two images.
