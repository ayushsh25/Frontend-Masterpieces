# 🔍 Search Functionality

**Search Functionality** is a simple and interactive web application built using **HTML5, CSS3, and JavaScript**. It allows users to search and filter a list of items dynamically based on their input, providing instant results through a clean and responsive interface.

This project demonstrates important frontend development concepts such as **DOM manipulation, event handling, string searching, filtering, and dynamic content updates**.

## 🚀 Features

* 🔍 Real-time search functionality
* ⚡ Instant filtering of items
* 🔤 Case-insensitive searching
* 📋 Dynamic list filtering
* 🎨 Clean and simple user interface
* 📱 Responsive design
* 🌐 Runs directly in the browser
* 💻 Lightweight and fast

## 🛠️ Technologies Used

* **HTML5** – Structure of the webpage
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Search logic and dynamic filtering

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Search-Functionality.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Enter a keyword in the search box.
5. The matching items will be displayed automatically.

## 💡 How It Works

The application listens for user input in the search field. JavaScript retrieves the available items from the DOM and compares their text with the entered search term.

The search is performed using case-insensitive matching. Items that match the entered keyword remain visible, while non-matching items are hidden dynamically.
