# 📝 Word Count

**Word Count** is a simple and interactive web application built using **HTML5, CSS3, and JavaScript**. It allows users to enter or paste text and instantly calculates the total number of words and characters.

The project provides a clean and responsive interface and demonstrates fundamental JavaScript concepts such as **DOM manipulation, event handling, string manipulation, and real-time data processing**.

## 🚀 Features

* 📝 Count words in real time
* 🔤 Count total characters
* ⚡ Instant results while typing
* 📋 Supports pasted text
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 🌐 Runs directly in the browser
* 💻 Lightweight and fast

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Word and character counting logic

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Word-Count.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Start typing or paste text into the text area.
5. The word and character counts will update automatically.

## 💡 How It Works

The application listens for changes in the text area using JavaScript. Whenever the user enters or removes text, the application processes the content and updates the word and character counts instantly.

Words are identified by separating the text based on whitespace, while characters are counted from the entered content.
