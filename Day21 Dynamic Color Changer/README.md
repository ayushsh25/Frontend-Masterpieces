# 🎨 Dynamic Color Changer

**Dynamic Color Changer** is a simple and interactive frontend web application built using **HTML5, CSS3, and JavaScript**. The project allows users to dynamically change the color of webpage elements through user interaction, creating an engaging and visually interactive experience.

This project demonstrates fundamental frontend development concepts such as **DOM manipulation, event handling, dynamic CSS styling, and JavaScript logic**.

## 🚀 Features

* 🎨 Dynamically change colors
* 🖱️ Interactive user controls
* ⚡ Instant color updates
* 🌈 Random or user-selected color options
* 🎯 Simple and intuitive interface
* 📱 Responsive design
* 🌐 Runs directly in the browser
* 💻 Lightweight and fast

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Color-changing functionality and user interaction

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Dynamic-Color-Changer.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Interact with the color controls to change the webpage colors dynamically.

## 💡 How It Works

The application uses JavaScript to detect user interactions and dynamically update CSS properties. When the user clicks a button or performs the supported action, JavaScript generates or selects a color and applies it to the targeted element.

This creates an immediate visual change without reloading the webpage.
