# 🖼️ Browse Image File Upload

**Browse Image File Upload** is a simple and interactive web application built using **HTML5, CSS3, and JavaScript**. It allows users to browse and select image files from their device and preview the selected image directly within the browser.

The project demonstrates important frontend development concepts such as **file input handling, JavaScript File API, DOM manipulation, event handling, image preview, and responsive UI design**.

## 🚀 Features

* 📁 Browse and select image files
* 🖼️ Preview selected images instantly
* 🔄 Change or select another image
* ✅ Basic file selection handling
* ⚡ Fast and lightweight
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 🌐 Runs directly in the browser
* 🔒 Image preview is handled locally in the browser

## 🛠️ Technologies Used

* **HTML5** – File input and application structure
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – File handling and image preview functionality

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Browse-Image-File-Upload.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Click the **Browse** or **Choose File** button.
5. Select an image from your device.
6. The selected image will be displayed as a preview.

## 💡 How It Works

The application uses an HTML file input element to allow users to select an image from their device.

JavaScript listens for the file selection event and uses the **File API** to access the selected file. The selected image is then displayed dynamically on the webpage using a browser-generated preview URL.

No server is required for the basic preview functionality.
