# 🔤 Vowel Count

**Vowel Count** is a simple and interactive web application built using **HTML5, CSS3, and JavaScript**. It allows users to enter text and instantly calculates the total number of vowels present in the given text.

The project demonstrates fundamental JavaScript concepts such as **string manipulation, loops, conditional statements, DOM manipulation, and event handling**.

## 🚀 Features

* 🔤 Count vowels in any text
* ⚡ Instant and accurate results
* 📝 Supports words, sentences, and paragraphs
* 🔡 Detects both uppercase and lowercase vowels
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 🌐 Runs directly in the browser
* 💻 Lightweight and easy to use

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Vowel counting logic and user interaction

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Vowel-Count.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Enter text into the input field.
5. Click the **Count Vowels** button.
6. The total number of vowels will be displayed.

## 💡 How It Works

The application takes the text entered by the user and checks each character to determine whether it is a vowel.

The program identifies the vowels **A, E, I, O, and U**, regardless of whether they are uppercase or lowercase, and increases the counter whenever a vowel is found.

### Example

```text
Input:
Hello World

Output:
Vowel Count: 3
```
