# 💰 Money Cash Calculator

**Money Cash Calculator** is a simple and interactive web application built using **HTML5, CSS3, and JavaScript**. It helps users quickly calculate the total cash amount by entering the quantity of different currency denominations.

The application automatically calculates the value of each denomination and provides the **total cash amount**, making it useful for managing daily cash, checking collections, and simplifying manual calculations.

## 🚀 Features

* 💵 Enter quantities for different denominations
* 🧮 Automatically calculate denomination-wise amounts
* 💰 Calculate the total cash amount
* ⚡ Instant and accurate calculations
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 🔄 Easy to update quantities
* 🌐 Runs directly in the browser
* 💻 Lightweight and fast

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Money-Cash-Calculator.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Enter the quantity of each currency denomination.
5. The application will calculate and display the total cash amount.

## 💡 How It Works

The application takes the quantity of each currency denomination as input and multiplies it by the respective denomination value.

For example:

```text
₹500 × 2 = ₹1000
₹200 × 3 = ₹600
₹100 × 5 = ₹500
```

The application then adds all denomination values to calculate the final total.

```text
Total Cash = ₹1000 + ₹600 + ₹500
           = ₹2100
```
