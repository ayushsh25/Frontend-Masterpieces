# 🎂 Age Calculator

**Age Calculator** is a simple and interactive web application built using **HTML5, CSS3, and JavaScript**. It allows users to enter their date of birth and calculates their age based on the current date.

The project demonstrates practical JavaScript concepts including **date handling, calculations, DOM manipulation, input validation, and event handling**.

## 🚀 Features

* 🎂 Calculate age from date of birth
* 📅 Uses the current date automatically
* 🔢 Displays age in years, months, and days
* ⚡ Fast and accurate calculation
* ✅ Date input validation
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 🌐 Runs directly in the browser
* 💻 Lightweight and easy to use

## 🛠️ Technologies Used

* **HTML5** – Structure and date input
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Age calculation and application logic

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Age-Calculator.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Enter your date of birth.
5. Click the **Calculate Age** button.
6. Your calculated age will be displayed.

## 💡 How It Works

The application takes the user's **date of birth** and compares it with the current date.

JavaScript's `Date` object is used to calculate the difference between the two dates and determine the user's age in **years, months, and days**.

### Example

```text
Date of Birth: 15/08/2003

Age: 23 Years, 0 Months, 24 Days
```
