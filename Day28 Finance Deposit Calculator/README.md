# 💰 Finance Deposit Calculator

**Finance Deposit Calculator** is a simple and interactive web application built using **HTML5, CSS3, and JavaScript**. It helps users estimate the maturity amount and interest earned on a deposit by entering the principal amount, interest rate, and investment period.

The project demonstrates practical frontend development concepts including **financial calculations, form handling, DOM manipulation, input validation, and dynamic result display**.

## 🚀 Features

- 💵 Enter deposit/principal amount
- 📈 Enter interest rate
- 📅 Enter investment duration
- 🧮 Calculate interest earned
- 💰 Calculate maturity amount
- ⚡ Instant calculation results
- ✅ Input validation
- 🎨 Clean and user-friendly interface
- 📱 Responsive design
- 🌐 Runs directly in the browser

## 🛠️ Technologies Used

- **HTML5** – Structure and input fields
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6)** – Calculation logic and dynamic results

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Finance-Deposit-Calculator.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Enter the deposit amount, interest rate, and investment period.
5. Click the **Calculate** button.
6. View the calculated interest and maturity amount.

## 💡 How It Works

The application takes the following inputs:

- **Principal Amount** – Initial amount deposited
- **Interest Rate** – Annual rate of interest
- **Time Period** – Duration of the deposit

The JavaScript program processes these values using the selected deposit calculation formula and displays the estimated interest and final maturity amount.

### Example

```text
Principal Amount: ₹50,000
Interest Rate: 7%
Duration: 2 Years

Interest Earned: ₹7,000
Maturity Amount: ₹57,000
```

*The example above is illustrative; actual results depend on the calculation method used by the application.*
