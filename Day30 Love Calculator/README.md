# ❤️ Love Calculator

**Love Calculator** is a fun and interactive web application built using **HTML5, CSS3, and JavaScript**. It allows users to enter two names and generates a playful compatibility percentage as an entertaining result.

This project demonstrates fundamental frontend development concepts such as **DOM manipulation, event handling, string manipulation, JavaScript logic, and responsive UI design**.

> ⚠️ **Disclaimer:** The compatibility percentage is generated for entertainment purposes only and does not represent a scientifically validated measure of relationship compatibility.

## 🚀 Features

- ❤️ Enter two names
- 💯 Generate a compatibility percentage
- ⚡ Instant results
- 🎨 Attractive and user-friendly interface
- 📱 Responsive design
- ✨ Interactive result display
- 🌐 Runs directly in the browser
- 💻 Lightweight and easy to use

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, layout, and visual effects
- **JavaScript (ES6)** – Calculation logic and user interaction

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Love-Calculator.git
```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Enter two names.
5. Click the **Calculate** button.
6. View the generated compatibility result.

## 💡 How It Works

The application accepts two names as input and processes them using JavaScript logic to generate a compatibility percentage.

The result is displayed dynamically on the webpage without requiring a page reload.
