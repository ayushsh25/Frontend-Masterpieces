# 🎨 HSL Color Generator

A simple and interactive web application that generates random HSL (Hue, Saturation, Lightness) colors with a single click. Users can view the generated HSL color value, preview the color instantly, and use it for web design and development projects.

## 🚀 Features

- 🎨 Generate random HSL colors
- 🌈 Live color preview
- 📋 Display HSL color values
- ⚡ One-click color generation
- 📱 Responsive and user-friendly interface
- 🌐 Runs directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
HSL-Color-Generator/
│── index.html
│── style.css
│── script.js
└── README.md
```

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the **Generate Color** button to create a random HSL color.
