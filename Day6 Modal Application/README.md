# 🪟 Modal Application

A simple and responsive web application that demonstrates how to create and manage modal pop-up windows using HTML, CSS, and JavaScript. The application allows users to open and close a modal with smooth interactions, making it useful for alerts, confirmations, forms, and additional content.

## 🚀 Features

- 🪟 Open and close modal pop-ups
- ✨ Smooth user interactions
- 🖱️ Close modal using a button or outside click
- ⌨️ Optional support for the **Esc** key
- 📱 Responsive design for all screen sizes
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the **Open Modal** button to display the pop-up window.
