# 🕒 Digital Clock

A simple and responsive Digital Clock web application built using HTML, CSS, and JavaScript. The application displays the current time in real time with automatic updates every second. It also shows the current date and supports a 12-hour format with AM/PM, providing a clean and user-friendly interface.

## 🚀 Features

- 🕒 Real-time digital clock
- 📅 Displays the current date
- 🕛 12-hour format with AM/PM
- ⚡ Updates every second automatically
- 📱 Responsive design for desktop and mobile
- 🎨 Modern and attractive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. The digital clock will automatically display the current time and date.
