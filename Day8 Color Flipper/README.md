# 🎨 Color Flipper

A simple and interactive Color Flipper web application built using HTML, CSS, and JavaScript. The application generates random colors and instantly changes the webpage's background with a single click. It also displays the corresponding HEX color code, making it a useful project for learning JavaScript DOM manipulation and color generation.

## 🚀 Features

- 🎲 Generate random colors with one click
- 🌈 Instantly change the background color
- 📋 Display the generated HEX color code
- ⚡ Fast and responsive user interface
- 📱 Mobile-friendly design
- 🎨 Clean and modern layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Click the **Flip Color** button to generate a random background color.
