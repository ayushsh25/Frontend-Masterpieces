# 📊 Percentage Calculator

A modern and responsive Percentage Calculator web application built using HTML, CSS, and JavaScript. The application helps users perform percentage calculations quickly and accurately through a simple, intuitive interface. It is designed for students, professionals, and anyone who needs to calculate percentages for academic, financial, or everyday purposes.

## 🚀 Features

- 📈 Calculate percentages instantly
- ⚡ Real-time and accurate calculations
- 🧮 Easy-to-use input fields
- 🎨 Clean and modern user interface
- 📱 Fully responsive design
- 🌐 Runs directly in any modern web browser
- 🚀 Lightweight and fast performance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

Percentage-Calculator/

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your preferred web browser.
4. Enter the required values.
5. Click the **Calculate** button to view the percentage result instantly.
